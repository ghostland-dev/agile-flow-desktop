# Agile Flow

Agile project management board (Kanban, tables, file uploads).

## Features

- Drag-and-drop Kanban with dnd-kit
- Data tables with TanStack Table
- File drop zone

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Framer Motion
- dnd-kit

## Getting Started

```bash
git clone https://github.com/ghostland-dev/agile-flow-desktop.git
cd agile-flow-desktop
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
